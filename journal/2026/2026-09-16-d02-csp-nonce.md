## Cambios Implementados

### 1. `apps/web/index.html` (+1 línea)
- Added `<meta property="csp-nonce" content="__CSP_NONCE__">`
- React 19 reads nonce from this meta tag and applies to dynamically created `<script>` and `<link>` elements

### 2. `apps/web/nginx.conf` (+46 líneas, nuevo archivo)
- **sub_filter**: `sub_filter '__CSP_NONCE__' $request_id;` — replaces placeholder with actual nonce
- **CSP header**: `default-src 'self'; script-src 'self' 'nonce-$request_id'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self' http://localhost:* https://localhost:*; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'`
- **Security headers**: X-Frame-Options, X-Content-Type-Options, Referrer-Policy

## Decisiones Arquitectónicas

### Nonce Generation
- **Mecanismo**: nginx `$request_id` (16 random bytes → 32 hex chars)
- **Aleatoriedad**: OpenSSL `RAND_bytes()` (128-bit cryptographic strength)
- **Unicidad**: regenerado por request
- **Cache safety**: no explicit caching of index.html

### React 19 Integration
- React 19 reads nonce from `meta[property=csp-nonce]`
- Applies to dynamically created `<script>` and `<link>` elements
- Does NOT apply to `<style>` elements → requires `style-src 'unsafe-inline'`

### CSP Directives
| Directive | Value | Justification |
|-----------|-------|---------------|
| `default-src` | `'self'` | All resources from same origin |
| `script-src` | `'self' 'nonce-$request_id'` | External scripts + dynamic scripts with nonce |
| `style-src` | `'self' 'unsafe-inline'` | React 19 dynamic `<style>` elements |
| `img-src` | `'self' data:` | Favicon uses data: URI |
| `font-src` | `'self'` | No external fonts |
| `connect-src` | `'self' http://localhost:* https://localhost:*` | Gateway (8100) + user-service (8099) |
| `object-src` | `'none'` | No plugins/embeds |
| `base-uri` | `'self'` | No `<base>` tag |
| `form-action` | `'self'` | No external form actions |
| `frame-ancestors` | `'none'` | No iframes |
